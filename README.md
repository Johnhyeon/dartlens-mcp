# DartLens

**Claude와 Codex가 전자공시(DART)를 직접 읽고 답하게 연결합니다**

[leetkey.kr](https://leetkey.kr) | [English](https://github.com/Johnhyeon/dartlens-mcp/blob/main/README.en.md) | [패치노트](https://github.com/Johnhyeon/dartlens-mcp/blob/main/PATCHNOTES.md)

---

AI에게 공시 PDF나 재무제표 캡처를 보여 주면 숫자를 잘못 읽기 쉽습니다. 단위가 백만 원인지 천 원인지, 3개월 값인지 누적 값인지, 연결인지 별도인지를 헷갈리면 숫자가 통째로 틀립니다.

DartLens를 연결하면 AI가 금융감독원 전자공시(DART)에서 공시 목록, 공시 원문, 정형 재무제표를 직접 가져와 답합니다. **어느 보고서의 어느 표, 어느 줄을 읽었는지 함께 적습니다.**

DartLens는 [LeetKit](https://leetkey.kr) FULL Package에 들어 있습니다. 시세와 수급을 보는 StockLens, 텔레그램 이야기를 정리하는 TelegramLens와 함께 씁니다.

## 실제로 돌려준 답

> 현대건설 수주잔고 알려줘

**현대건설 수주잔고** `DART 사업보고서 원문`

| 시점 | 수주잔고 | 근거 |
|---|---:|---|
| 2025년 말 | 957,041.6억원 | 사업보고서(2025.12), '(단위 : 백만원)' 표, 원문 58행 중 합계행 1행 |
| 2024년 말 | 빠짐 | 단위 표기가 없는 표가 있어 합계를 만들지 않음 |

단위를 잘못 읽으면 100배, 10만 배 어긋납니다. 공시 표의 합계 줄을 그대로 읽고, 단위를 확신할 수 없으면 숫자를 만들지 않고 빠졌다고 적습니다.

## 이렇게 물어봅니다

```
삼성전자 최근 한 달 공시 뭐 있었어?
에코프로비엠 최근 5% 대량보유 변동이랑 임원 매매 정리해줘
LG에너지솔루션 사업보고서에서 수주 얘기 나온 부분만 찾아줘
```

```
SK하이닉스 최근 3년 매출이랑 영업이익 분기별로 보여줘
이번 실적 시즌에 영업이익이 크게 늘어난 종목 정리하고 엑셀로 저장해줘
```

## 되는 것

- **공시 목록과 원문:** 기간과 유형으로 목록을 뽑고, 짧은 공시는 본문을 발췌하고, 긴 보고서는 목차와 원문 링크를 줍니다. 키워드로 본문을 검색합니다.
- **재무제표:** 매출, 영업이익, 순이익, 자산, 부채, 자본 같은 핵심 계정을 당기, 전기, 전전기로 비교합니다. 필요하면 전체 재무제표를 봅니다.
- **수주잔고:** 사업보고서, 분기보고서, 반기보고서의 표에서 수주잔고와 계약잔액 추이를 뽑습니다.
- **지분 변동:** 5% 대량보유 변동과 임원, 주요주주의 소유 변동을 봅니다. 시세에는 안 나오는 돈의 움직임입니다.
- **실적 시즌 스캔:** 실적을 낸 종목을 한 번에 훑어 표로 정리하고 엑셀로 저장합니다.

도구는 11개입니다. 도구 목록과 응답에 붙는 결과 메타 규약은 [도구 안내](https://github.com/Johnhyeon/dartlens-mcp/blob/main/guides/TOOLS.md)에 있습니다.

## 숫자 이름표 원칙

- **읽은 곳을 적습니다.** 어느 보고서의 어느 표, 어느 줄인지 적어서 원문과 바로 맞춰 볼 수 있습니다.
- **단위를 확신할 수 없으면 숫자를 만들지 않습니다.** 빠졌다고 적습니다.
- **3개월 값과 누적 값을 나눕니다.** 분기와 반기 손익은 두 칸으로 따로 적습니다.
- **목록이 잘렸으면 잘렸다고 적습니다.** "표시 8건 / 전체 11건"처럼 적고, 보여 준 게 전부인 것처럼 말하지 않습니다. "그런 공시는 없다"는 끝까지 확인했을 때만 말합니다.

## 설치와 가격

- **설치:** LeetKit Manager에서 버튼을 눌러 설치하고 받은 키를 붙여 넣습니다. 명령어를 칠 일은 없습니다.
- **DART 인증키 (무료):** [opendart.fss.or.kr](https://opendart.fss.or.kr)에서 무료로 받아 Manager의 DartLens 카드 [활성화]에 붙여 넣습니다. 분당 1,000건, 하루 20,000건까지 조회할 수 있습니다. 키는 PC의 보안 저장소(Windows 자격 증명, macOS 키체인)에 보관합니다.
- **체험:** 14일 무료 체험으로 Lens 3개를 전부 써 볼 수 있습니다. 카드 등록 없이 이메일만 있으면 됩니다.
- **가격:** 한 번 결제, 월 구독 없음. DartLens는 단품으로 팔지 않고 LeetKit FULL Package에 들어 있습니다.

체험 신청과 가격은 **[leetkey.kr](https://leetkey.kr)** 에서 확인하세요.

## 투자 조언이 아닙니다

DartLens는 공개된 공시 데이터를 AI가 직접 조회하도록 연결하는 데이터 도구입니다. 투자자문이나 투자일임, 종목 추천 서비스가 아니며, 특정 종목의 매수나 매도를 권유하지 않고 매매 주문 기능도 없습니다. 데이터는 출처 사정에 따라 늦거나 틀릴 수 있고, AI의 답변도 참고 자료입니다. 투자 판단과 그 결과에 대한 책임은 투자자 본인에게 있습니다.
